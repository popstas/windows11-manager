# icons

`head-badge.ico` — значок head-сессии claude (`claudeWt.windowIcons.head`,
пусто — этот файл): синий круг с белой обводкой, внутри белая оргсхема (узел
сверху, два снизу). Решение Стаса 17.11.2026, сменил корону: та плохо
читалась поверх части иконок проектов. Один файл на оба режима `headMode`:
кадры 16/20/24 — значок в углу кнопки на панели задач (`badge`, служба берёт
маленький кадр), 32/48/64/256 — иконка окна вместо иконки проекта (`icon`).

Рисунок свой, без чужих наборов. Генератор — `head-badge.py` (Pillow):
`python3 icons/head-badge.py` перезаписывает `head-badge.ico` рядом.

Иконки проектов сюда не кладутся: это личные картинки и чужие логотипы, а
репозиторий публичный. Пути к ним задаёт живой конфиг машины —
`claudeWt.windowIcons.profiles` и `claudeWt.projects[].icon`, абсолютными.
