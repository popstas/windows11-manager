# icons

`crown.ico` — окно head-сессии claude (`claudeWt.windowIcons.head`, пусто —
этот файл): значком в углу кнопки на панели задач (`headMode: overlay`, берётся
кадр 16x16 — в нём корона читается) или вместо иконки окна (`replace`). Нарисован из эмодзи 👑 набора [Noto Emoji](https://github.com/googlefonts/noto-emoji)
(картинки — Apache License 2.0).

Иконки проектов сюда не кладутся: это личные картинки и чужие логотипы, а
репозиторий публичный. Пути к ним задаёт живой конфиг машины —
`claudeWt.windowIcons.profiles` и `claudeWt.projects[].icon`, абсолютными.
